Where this report has been wrong

The status reporting has been wrong four times in four days, always in the flattering direction. Worth stating, because it is the reason for the evidence column above.

Called an agent we run a stranger

Upkeep #81 was recorded as the first registered by somebody outside the project, on the strength of one address not matching two hardcoded ones. It was a Grok agent. The beta gate item was ticked and had to be un-ticked.

Counted registrations as executions

A hand-rolled query grouped every application call by sender and reported five keepers. Filtering on the execute selector gives two. An execution is a call to execute, not a call to the app.

Reported a branch green when it was red

A CI run from before the change was read as current. It reproduced locally in one command.

Shipped a contract whose tests could not catch its bug

Rot authorized against an app id instead of an app address. 15 unit tests passed before and after the fix, because the mock does not model address derivation. Only the live chain caught it.
